## 🧭 The 6 Core Pillars of the Journey

Represented directly in the banner, our curriculum is engineered across 6 foundational pillars that transform raw signals into intelligent automated decisions:

| 📈 **1. Data Preprocessing** | 🔍 **2. Exploratory Data Analysis** | ⚙️ **3. Machine Learning Algorithms** |
| :--- | :--- | :--- |
| • Python 3.9+ Fundamentals & Data Structures<br>• Missing Data Handling (`CCA`, `SimpleImputer`)<br>• Outlier Isolation (`IQR`, `Z-Score`, Percentile Capping)<br>• Normalization, Standardization & Power Transforms | • Univariate, Bivariate & Multivariate Analysis<br>• Automated Profiling (`ydata-profiling`)<br>• Custom Seaborn & Matplotlib Dashboards<br>• Correlation Heatmaps & Statistical Testing | • Linear, Ridge & Polynomial Regression<br>• Logistic Regression & Softmax Multi-Class<br>• SVM, Decision Trees, KNN & Naive Bayes<br>• Ensembles: Bagging, Random Forest, AdaBoost, XGBoost<br>• Clustering: K-Means++, Agglomerative, DBSCAN |
| 🧠 **4. Model Evaluation** | 🎛️ **5. Hyperparameter Tuning** | 💡 **6. Real-World Projects** |
| • Confusion Matrix, ROC-AUC & PR-AUC Curves<br>• Precision, Recall, Macro/Micro F1-Scores<br>• Bias-Variance Trade-Off & Generalization Error<br>• Classification Reports on Binary & Multiclass Datasets | • Bayesian Optimization with Optuna<br>• Tree-structured Parzen Estimator (TPE)<br>• Automated Trial Pruning & Optimization History<br>• Hyperparameter Slice & Importance Visualizations | • End-to-End Salary Prediction Flask Web App<br>• Interactive Streamlit Logistic Decision Boundary Tool<br>• Leak-Free Scikit-Learn Pipelines & Pickling<br>• Web Scraping AmbitionBox Corporate Data |

```bash
git clone https://github.com/swapnil3104/Machine-Learning-Journey.git
cd Machine-Learning-Journey
```

### 2. Create and Activate a Virtual Environment
```bash
# Windows
python -m venv venv
venv\Scripts\activate

# macOS / Linux
python3 -m venv venv
source venv/bin/activate
```
