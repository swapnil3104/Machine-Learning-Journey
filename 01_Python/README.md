# 🐍 01. Python Fundamentals

## 📌 Folder Overview
Welcome to the **Python Fundamentals** module of the Machine Learning Journey! Python is the universal language of modern Data Science, Machine Learning, and Artificial Intelligence. This folder serves as the cornerstone of your learning journey, covering foundational syntax, variable assignments, standard data types, operators, and essential data structures.

### Why is this topic important?
Before building machine learning models or writing complex algorithms, you must have a solid grasp of Python programming. Python provides clean, readable syntax and a massive ecosystem of scientific computing libraries (such as NumPy, Pandas, and Scikit-Learn). Mastering core Python concepts ensures you can efficiently manipulate data, construct custom logic, and debug machine learning workflows.

### What You Will Learn
- Python setup, basic syntax, and executing Python scripts (`.py`) and Jupyter Notebooks (`.ipynb`).
- Variable declaration, dynamic typing, and memory assignment in Python.
- Primitive data types including Integers, Floats, Strings, and Booleans.
- Arithmetic, comparison, logical, and bitwise operators.
- Core built-in data structures: **Lists** (mutable sequences) and **Tuples** (immutable sequences), including indexing, slicing, and method operations.

---

## 📚 Topics Covered

Organized logically from fundamental concepts to core data structures:

### 🟢 Beginner
- **Introduction to Python**: Executing code, printing outputs, string formatting.
- **Variables & Memory**: Naming conventions, dynamic typing, `id()` and assignment memory model.

### 🟡 Intermediate
- **Primitive Data Types**: Numeric types (`int`, `float`), textual data (`str`), and truth values (`bool`).
- **Python Operators**:
  - Arithmetic (`+`, `-`, `*`, `/`, `//`, `%`, `**`)
  - Comparison (`==`, `!=`, `>`, `<`, `>=`, `<=`)
  - Logical (`and`, `or`, `not`)

### 🔴 Advanced
- **Sequences & Collections**:
  - **Lists**: Creation, append/extend/insert methods, indexing, slicing `[start:stop:step]`, and mutability.
  - **Tuples**: Creation, immutability, tuple packing & unpacking, tuple methods (`count`, `index`).
