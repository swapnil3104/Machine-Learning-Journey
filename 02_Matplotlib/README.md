# 📊 02. Data Visualization with Matplotlib

## 📌 Folder Overview
Welcome to the **Matplotlib** module! Matplotlib is the foundational data visualization library in the Python scientific stack. This folder covers everything from basic 2D plotting to custom multi-series visualizations using real-world datasets such as IPL cricket statistics.

### Why is this topic important?
Data visualization is an essential step in Exploratory Data Analysis (EDA). As a machine learning practitioner, visual charts help you identify data trends, detect outliers, understand feature distributions, evaluate correlations, and communicate findings effectively to stakeholders.

### What You Will Learn
- Fundamental plotting syntax using Matplotlib's `pyplot` interface (`plt.plot`, `plt.show`).
- Customizing chart styling: line colors, line styles, markers, labels, titles, grids, and legends.
- Constructing diverse chart types: Line plots, Bar charts, Scatter plots, and Pie charts.
- Analyzing multi-series datasets, season-by-season performance, and head-to-head player comparisons using real-world tabular CSV data.

## 📚 Topics Covered

Organized logically from basic chart creation to multi-dataset analysis:

### 🟢 Beginner
- **Pyplot Fundamentals**: Creating basic line charts, setting x/y labels, plot titles, and legend overlays.
- **Customizing Visuals**: Configuring colors, markers, linewidths, and axis limits.

### 🟡 Intermediate
- **Core Chart Types**:
  - **Bar Charts**: Categorical feature comparisons.
  - **Scatter Plots**: Relationship discovery between continuous numerical variables.
  - **Pie Charts**: Proportional breakdown and percentage distributions.

### 🔴 Advanced
- **Complex Multi-Series Visualizations**:
  - Head-to-head player analysis (e.g., Rohit Sharma vs. Virat Kohli).
  - Match-by-match innings trends (e.g., Chris Gayle's 175-run record).
  - Aggregating season records and boundary trends (Fours & Sixes analysis).
