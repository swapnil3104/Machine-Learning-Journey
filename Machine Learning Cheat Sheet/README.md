# 📌 Machine Learning Visual Cheat Sheets

## 📌 Folder Overview
Welcome to the **Machine Learning Cheat Sheet** gallery! This folder contains a curated collection of high-resolution visual cheat sheets, infographics, decision boundary diagrams, and mathematical summary notes covering key concepts across the entire Machine Learning Journey.

### Why is this topic important?
Visual cheat sheets condense complex mathematical derivations, algorithmic steps, and theoretical frameworks into easy-to-digest visual infographics. They serve as an invaluable quick-reference resource during revision, coding projects, model debugging, and technical interview preparation.

### What You Will Learn
- **Regression Concepts**: Visual summaries for Simple Linear Regression, Multiple Linear Regression, Polynomial Regression, and Ridge Regularization.
- **Classification Algorithms**: Decision surfaces, hyperplanes, and intuition for Logistic Regression, Naive Bayes, KNN, Support Vector Machines (SVM), and Decision Trees.
- **Optimization & Evaluation**: Graphical breakdowns of Gradient Descent, Model Evaluation metrics, and the Bias-Variance Trade-off.

## 📚 Topics Covered

Organized logically across core machine learning domains:

### 🟢 Foundational Data Analysis & Metrics
- **Exploratory Data Analysis**: Data distributions, outlier detection, and correlation summaries.
- **Model Evaluation**: Confusion matrices, Precision, Recall, F1-Score, and ROC curves.

### 🟡 Linear & Regularized Regression Models
- **Simple & Multiple Linear Regression**: OLS fitting, slope/intercept formulas, and residual plots.
- **Polynomial & Ridge Regression**: Curved feature boundaries, L2 regularization penalties, and weight shrinkage.

### 🔴 Advanced Classification & Optimization
- **Optimization**: Gradient Descent step sizes, learning rate dynamics, and cost function landscapes.
- **Classifiers**:
  - **KNN**: Decision surfaces and spatial distance metrics.
  - **Logistic Regression**: Sigmoid function mapping and log-loss curves.
  - **Naive Bayes**: Probability tables and Bayes Theorem breakdowns.
  - **Decision Trees & Regression Trees**: Node splitting graphics, Gini vs Entropy, and pruning.
  - **SVM**: Support vectors, maximum margins, and Kernel trick illustrations.
  - **Bias-Variance Trade-Off**: Overfitting vs underfitting target diagrams.
